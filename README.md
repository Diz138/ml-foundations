# ml-foundations
A structured collection of ML experiments focused on core modeling techniques, evaluation, and practical tradeoffs.

## Setup

```bash
# macOS with Homebrew:
brew install uv

# Linux / Windows or other platforms:
# Install uv using the official instructions for your OS:
# https://docs.astral.sh/uv/getting-started/installation/

# Once uv is installed, create and activate a virtual environment:
uv venv
source .venv/bin/activate
uv pip install -e ".[dev]"
